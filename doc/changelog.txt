expchangeclass 1.0.0
====================
Fork of eZChangeclass for Exponential Legacy / Exponential 6 on PHP 8, taking
the OpenContent fork as its base and the mapping pre-selection from the Netgen
fork.

- Conversion runs in one transaction and rolls back as a unit. Failures no
  longer leave an object with some attributes moved and the rest not, and the
  contentclass_id change moved inside the transaction.
- die() inside the attribute loop replaced with exceptions, so a failure can be
  rolled back and reported instead of ending the request mid-write.
- The attribute mapping is validated against both class data maps before
  anything is written.
- convertObject() takes an out parameter for the failure reason and its result
  is honoured by the module and the batch script.
- classconvert.php pages correctly: the window steps over objects that failed,
  which previously made the loop repeat the same batch forever.
- Parameter file parsing rejects malformed and blank lines.
- Text to ezxmltext conversion escapes the value first; content containing an
  ampersand or an angle bracket no longer produces invalid xml.
- Relation list to bloc converter rewritten on DOMDocument, replacing the
  removed PHP 4 eZXML API.
- changeclass.ini declared [ezstring] twice, which made ezstring to ezxmltext
  unreachable. One group per source datatype now, dispatching on destination.
- Converter methods declared static, matching how they are invoked.
- changeclass/convert policy function added to all three views.
- Caches cleared every batch pass, not only on non-quiet runs.
